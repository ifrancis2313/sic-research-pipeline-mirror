# Every phase boundary gets a versioned domain/range contract and its own input gate — not just Phase 1

Each phase in the QEPM pipeline commits to a fixed, versioned output shape (its "range") and validates its own upstream input (its "domain") against the previous phase's contract before doing anything with it. This extends a "pure function, fixed domain/range" composition rule from a property of the *pipeline as a whole* into an explicit, checked gate at *every* individual phase boundary — Phase 1 into Phase 2, Phase 2 into Phase 3, and so on — so that malformed or out-of-range data is caught and rejected at the boundary where it enters, rather than silently corrupting whatever phase discovers it downstream.

Phase 1's contract specifically is a two-part shape, not one flat structure: a **Per-security panel** (FIGI × date × fields) plus a separate **Macro series** (date × fields, no security key) for market-wide inputs like Fed funds rate, Fama-French factor returns, and VIX. These are kept separate rather than broadcasting macro values into every security row, since they have fundamentally different grain and only some factors need the macro context at all.

Phase gates also run a **leakage check** wherever a phase compresses/summarizes raw history into a derived field (e.g. a rolling factor score) — confirming the derived value only used information actually available as of that point in time, and that Universe membership (Russell 1000) is applied point-in-time rather than today's constituent list projected backward. This guards against lookahead and survivorship bias inflating a backtest relative to how the strategy would actually have performed live.

The alternative — validating only at the Phase 1/2 boundary, or trusting each phase's internal correctness without a checked contract — was rejected because data sourcing here is manual and heterogeneous (CSV/Parquet/Excel, from Bloomberg/FactSet/other, sometimes hand-assembled by analysts), which makes silent malformed-data propagation a real and likely failure mode, not a hypothetical one.
